Lycorine iOS 27 Cryptex1 TSS client: on a physical device, import a directory containing Restore/BuildManifest.plist. The app verifies SHA-384 of the four mandatory Cryptex assets and that the trust cache is marked for personalization, reads AppleImage4 chip identifiers and the current cryptex nonce via iDevice, constructs a fresh Cryptex1 request matching public idevice/src/tss.rs, and sends it via HTTPS to gs.apple.com. A new signed local copy is only saved when Apple's response actually contains an Image4 ticket. No installation happens automatically. The original TSS server bug was patched, and a ticket received is not evidence that iOS accepted or installed the cryptex. Test on real hardware; Simulator cannot emulate this. Diagnostics intentionally omit nonces, ECIDs and ticket bytes. Source reference: https://github.com/jkcoxson/idevice/blob/master/idevice/src/tss.rs
